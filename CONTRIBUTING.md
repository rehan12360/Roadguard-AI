# Contributing to RoadGuard AI

First off, thank you for considering contributing to RoadGuard AI! It's people like you that make open-source a great community.

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) to see if someone else has already raised it. If not, feel free to open a new issue.

## 2. Fork & create a branch

If this is something you think you can fix, then fork RoadGuard AI and create a branch with a descriptive name.

## 3. Implement your fix or feature

At this point, you're ready to make your changes. Feel free to ask for help; everyone is a beginner at first 😸

## 4. Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with RoadGuard AI's master branch.
Then create a pull request to the `main` branch.

## AI & ML Model Contributions
When submitting updates to the YOLOv8n weights (`roadguard_custom.pt`), please provide validation metrics (mAP, Precision, Recall) on a standardized dataset to prove the new model outperforms the current iteration.
